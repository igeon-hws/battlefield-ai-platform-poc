# UI_GUIDE

## 방향과 구성

지도 중심, 차콜 표면, 절제된 강조와 정돈된 정보 밀도를 사용한다. GOTHAM/LATTICE는 시각 참고이며 실제 제품 토큰을 재현하지 않는다. 장식용 네온/그라데이션/유리 효과·로봇 아바타·거대한 환영 채팅창·지속 점멸은 사용하지 않는다. 기술 계약은 [ARCHITECTURE](ARCHITECTURE.md), 시나리오는 [PRD](PRD.md)를 따른다.

| 화면 | 중심 정보 |
| --- | --- |
| 육군 | 장비/조직/보고/일지/활동/문서, native 코드·벡터·수동 제어 |
| 해군 | 자군/접촉·항적/편성/전문/ACK/association/문서, 복합 ID·기관/임무 상태 |

| 플랫폼 | 상시 지도·원천 상태와 AI 채팅, 대화/비교 이력, F1~F7/기준보고, 근거·계산·A/B/C (v3는 OFF/ON) |

## 레이아웃과 시각 토큰

v4는 viewport 높이의 고정 shell이며 상단58px/하단27px, 가변 지도와 우측 채팅 `clamp(360px,32vw,460px)`로 구성한다. 1024px 이상은 나란히 유지하고 미만은 상단 지도 `clamp(180px,30dvh,300px)`와 하단 채팅으로 배치한다. 좁은 화면의 상단/하단은50px/23px이며 높이600px 이하에서는 지도를 `clamp(100px,25dvh,150px)`로 줄여 composer를 유지한다. 대화 본문만 독립 스크롤하고 입력/채팅 헤더를 고정한다. 이력과 객체 목록은 명시적으로 여는 보조 패널이다. legacy/v3 화면은 기존 레이아웃을 유지한다.

## 지도와 원천 기록

저채도 MapLibre 2D 지리 지도, WGS84·축척·북쪽·마지막 시각·출처를 유지한다. 아군 파란 직사각형/적군 붉은 마름모/미상 회색 원과 소속 텍스트를 함께 사용한다. 유형·운용 상태·선택 링을 분리한다. 이동 방향/속도는 벡터로 표시하며 tick이 사용자의 줌/팬을 바꾸지 않는다.

원천 ID·관측 시각·출처·native 상태를 보존하고 자산/contact/track/문서를 같은 개수로 합치지 않는다. 목록 identity는 자체 ID를 문서 참조보다 우선하고 system/tab을 포함한 안정 key를 사용한다. EX-01 참조가 여러 기록에 있어도 그 기록의 ID를 대체하지 않는다.

배경 지도 장애와 원천 장애를 구분한다. 지도 실패 시 목록·객체·좌표를 유지한다. 최초 연결/epoch 전환 때만 시나리오 범위를 맞추며 legacy 접경120개와 v3 고유7개를 혼용하지 않는다.

## 분석과 이력

요약→범위/시각→근거→실행 상세 순서다. 실행 상세는 실제 함수명·서버/원래 MCP 도구명·인수·결과/실패·evidenceId·시간이며 내부 사고 과정을 표시하지 않는다. 사실/추론/의미 해석/계산 배지를 구분한다. 모델 작성 표와 계산 evidence의 표를 혼동하지 않는다.

conversation별 질문/응답 타임라인에 run별 상세를 연결한다. 새로고침/이력 열기는 대화를 복원한다. 늦은 응답이 사용자가 보고 있는 과거 응답/비교 대상을 바꾸지 않는다. 이벤트는 관련 객체/분석으로 연결하되 tick으로 읽기 위치를 이동시키지 않는다.

준비/실행/완료/실패/중단, unknown/0개/잘림/단절/Graph 지연을 다른 문구로 표현한다. UTC 또는 명시한 시간대와 함께 원천 관측·snapshot 기준·분석 생성 시각을 구분한다.

## OFF/ON과 세 방책

입력 옆 모드 선택과 별도 동일 기준 비교를 제공한다. 모드 변경은 새 대화이며 과거 모드를 소급 변경하지 않는다. OFF의 Semantic 상태는 장애가 아닌 사용 안 함이다. ON 준비 실패 시 입력을 보존하고 이유·재시도·명시적 OFF 전환을 제공한다.

비교 상단은 공통 질문/snapshot 집합/기준보고·T0/Graph·규칙/모델 예산이다. 두 열은 각 runId·진행·결과·한계·도구·근거·시간/token을 가진다. 한쪽 실패도 보존하고 ON 승리 배지를 자동 부여하지 않는다. 좁은 화면은 탭을 사용하며 공통 조건 높이/스크롤을 제한해 전환 버튼을 밀어내지 않는다.

관계 상세는 필요한 경로와 source/assertion/rule/version/graphVersion을 제공한다. 전체 Graph를 무조건 펼치지 않는다. 원천 기록 수와 canonical 수를 구분하며 OFF UI가 의미 결과를 대신 채우지 않는다.

Fabric의 공통 버전 선택기는 생성 일시(KST)·데이터셋·충돌을 피한 짧은 ID를 표시하고 ID/데이터셋/시각 검색과 생성 날짜(UTC) 필터를 제공한다. 현재 활성과 조회 중 배지를 구분하고 전체 ID 복사를 제공한다. 활성 READY v3/v4를 최초 선택하되 이후 활성 변경/목록 갱신으로 조회 버전을 바꾸지 않는다. 활성 버전이 없으면 직접 선택한다. 생성 시각과 원천 기준 시각은 구분하며 누락 메타데이터는 정보 없음으로 표시한다.

Graph 탐색은 유형별 레코드 수→검색 목록→선택 객체의 1-hop 관계→상세 순서다. 조직/배정·동일성/원천 참조·보고 계보 프리셋과 관계 필터, 방향 화살표·유형 형태/범례, 줌/팬/화면 맞춤을 제공한다. 추가 확장은 노드/관계 ID로 병합하며 화면 상한을 넘으면 필터 축소를 안내한다. 상세는 scalar 속성, 복합 원천 참조, 규칙/문서 이동, evidence 조회와 접힌 원본 JSON을 제공한다. 정의/절차 payload를 가짜 관계로 그리지 않는다. 저장 Graph는 현재 live 상태를 대신하지 않는다.

좁은 화면은 목록/그래프/상세 탭을 사용하고 관계 목록은 키보드 대체 경로다. 버전/필터 변경 시 이전 선택을 비우고 늦은 응답을 무시한다. Graph 없음, 인증/연결 오류, 검색 0개, 고립 노드, 깊이/개수 제한에 따른 부분 결과를 구분한다. Graph 장애가 원천·Catalog 조회를 막지 않는다. 실제 수치와 제한은 [ARCHITECTURE](ARCHITECTURE.md), 검증 결과는 [STATUS](IMPLEMENTATION_STATUS.md)를 따른다.

방책은 한 응답의 대안3개이며 OFF/ON은 run2개의 비교다. 버튼/제목/선택을 분리한다. 방책 열은 같은 폭·최소300px·간격16px으로 목표/근거/장단점/가정/제약을 비교한다. 부족한 폭은 비교 영역만 가로 스크롤한다. 응답별 선택을 표시하고 복귀 시 지도 맥락을 유지한다. 선택은 원천 명령 전송이 아니다.

## v5 별도 진입과 객체 상세

현재 기본 진입은 조건 선택 화면이다. `/demo/a` 원천 데이터, `/demo/b` 문서 지식, `/demo/c` 구조화 지식, `/demo/compare` 동일 기준 비교로 들어간다. 각 페이지는 v4의 지도·고정 composer·반응형 shell을 공유하고, 상단에 조건을 고정 표시한다. v5 composer에는 A/B/C 변경 select를 두지 않는다. ‘조건 선택’으로 돌아가 명시적으로 이동한다. 대화/스크롤/지도 선택은 페이지별로 복원하고 통합 상세·문서·늦은 응답을 다른 조건에 재사용하지 않는다.

A/B/C 모두 ‘원천 탐색’에서 세 체계의 자원·페이지·native 필드와 출처/시점을 조회한다. A는 문서·Semantic 통합 상세가 없다. B는 Fabric 문서 catalog/검색/본문을 추가한다. C는 같은 문서와 구조화된 연결을 제공한다. 원천에 원래 있는 매핑/참조를 A/B에서 감추지 않는다. 운영자 Fabric 콘솔과 데모 조건 진입을 구분한다.

C에서 지도 객체를 선택하면 기본 자산→군수 자산→정비 작업→관련 부품/재고/예약→화물/수송의 상세를 지도 위 보조 패널로 보여 준다. 원천 필드·수량·상태는 각 원천의 값이며 부품을 차량의 직접 속성으로 합치지 않는다. 기준 시각·상태 변경 시각(있을 때)·마지막 성공 수신 시각을 따로 표시한다. 누락은 정보 없음이다. 펼친 연결 근거에서 실제 relation/등록 기록·규칙/adapter·Graph·지식 버전과 고정 문서를 확인한다. 원본 JSON은 접힌 상세다.

객체 클릭/상세 새로고침은 Agent를 실행하지 않는다. ‘이 객체에 질문 작성’은 원천 ID가 든 초안만 만들고, 사용자가 전송해야 분석한다. 미연결/복수 후보/충돌·오래된 Graph는 확정 통합하지 않는다. 이미 조회한 Graph로 새로고침할 때 부분 단절이면 가능한 원천과 coverage를 보여 준다. 최초 조회의 Graph 준비가 불가능하면 이유와 재시도를 보이고 기본 원천 객체 정보는 유지한다.

별도 비교 페이지에서 동일 질문·세 원천 snapshot·B/C 지식 집합을 고정한다. 비교 이력/탭/확대와 run별 근거·방책 선택을 유지하고 개별 페이지의 대화 이력과 섞지 않는다. 모바일 상세 패널은 닫아서 지도·composer로 돌아올 수 있으며 문서 근거 이동은 본문을 목록보다 먼저 보여 준다. 군수 독립 UI는 :4120에서 원천 자원 선택·정비 상태·시뮬레이션 제어, 해군의 ‘수송·입항’은6시간 지연 제어를 제공한다.

## v4 호환 지식 비교 화면

플랫폼은 지도와 AI 채팅을 첫 화면에 함께 표시한다. 지도는 표시용 projection이며 객체 선택/필터를 Agent 근거에 자동 주입하지 않는다. 최초 데이터 범위 맞춤 이후에는 질문·poll·이력·비교로 지도 인스턴스와 시점을 초기화하지 않는다. 객체 목록/선택 상세는 원천 ID·좌표·관측 시각·native 상태를 제공한다. 원천 갱신 실패 시 마지막 객체와 별도 지연 안내를 유지하고 배경 타일 장애와 구분한다.

같은 대화의 모든 run을 생성 순서의 사용자 질문/Agent 응답 타임라인으로 표시한다. 결과/도구·근거/방책 선택은 공통 RunPanel을 사용한다. composer에 A 원천 데이터/B 원천+문서 지식/C 원천+구조화 지식 선택, 여러 줄 입력, 실행과 동일 기준 비교를 둔다. F1~F7와 R0 기준보고는 옵션 메뉴에 둔다. Enter 전송/Shift+Enter 줄바꿈, 한글 IME 조합 중 전송 방지·중복 전송 방지를 제공한다. 실행 진행은 실제 run/tool 상태만 표시하며 실패 시 입력을 보존한다. A↔B는 지식 제공, B↔C는 같은 지식의 구조화·규칙 재사용이다.

읽는 위치가 하단일 때만 새 응답을 따라가며 위의 답변을 읽고 있으면 ‘새 내용 보기’로 복귀한다. 이력 drawer에서 대화/비교를 다시 열고, 새로고침 시 선택 모드·대화/비교·스크롤·지도 시점/선택 객체를 sessionStorage의 UI 식별자로 복원한다. 응답 본문은 저장하지 않고 서버에서 다시 읽는다. 모드 변경은 새 대화이며 늦은 요청 결과는 사용자가 이동한 대화/초안을 덮어쓰지 않는다. 삭제된 대화/비교는 안내 후 정리한다.

채팅 안 비교 결과는 A/B/C 탭이며 명시적 확대 dialog에서 데스크톱 세 열을 제공한다. 좁은 확대 화면도 탭으로 전환한다. 닫으면 원래 지도·대화·읽기 위치를 유지한다. 공통 snapshot·지식 version/hash·Graph·실행 순서·준비 조건은 접힌 상세로 확인한다. 한 비교군 실패도 남기며 승자를 자동 선정하지 않는다. 세 방책과 세 비교군은 별도 기능이다. v3 화면은 원래 OFF/ON 정책을 유지한다.

Fabric v4 진입 시 지식 문서를 먼저 보여 준다. 발행/적용 체계와 Fabric 관리 책임, namespace/문서 version/hash/knownAt/검토 revision을 구분하고 전체 본문을 읽는다. Graph의 Fabric documentRef는 그 Graph에 고정된 지식 버전으로 이동한다. 과거 v3 source documentRef는 기존 Graph 상세를 유지한다. 지식 탭은 Graph 없이 조회하며 Graph 장애가 문서 읽기를 막지 않는다.

## 접근성

색 외 텍스트·모양, 키보드 포커스·접근 가능한 버튼명·툴팁을 제공한다. 본문 대비4.5:1, 큰 글자/핵심 비텍스트3:1을 기준으로 확인한다. reduced-motion을 존중하며 점멸/타이핑 장식을 피한다. 입력·실패·재시도는 확대/좁은 화면에서도 접근 가능해야 한다.
