- Gemma4, GPT(상용) 모델 중 선택할 수 있도록 반영 (env에 GEMMA 관련 있음)
- C 답변의 "분석 과정"이 주장마다 반복되어 같은 그래프가 여러 번 보인다(예: 주장 4개가 근거 2개를 나눠 인용해 4번 표시). 근거(업무 질의 결과)별로 한 번만 보여주고, 주장은 그 근거를 가리키도록 정리할 것.
